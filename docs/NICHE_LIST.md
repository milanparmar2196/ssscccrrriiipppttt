The starting master list of niches for the faceless AI Script Writer.
This is **seed data for Admin Taxonomy, not a limit** — the system is
fully dynamic: Admin can add unlimited categories, niches and
sub-niches beyond this list at any time (Notion Section 46).

**Entity Focus** = the main kind of thing a niche's videos are about.
This tag decides which Bible registry the niche needs in the next step
(Character Registry, Place Registry, Herb/Ingredient Registry, and the
proper registry for every other entity type):

`PERSON` people · `PLACE` locations · `SUBJECT` knowledge topics ·
`EVENT` incidents/moments · `CREATURE` animals · `STORY` fictional
worlds/tales · `ORGANISATION` companies/institutions · `PRODUCT`
things/machines · `CONCEPT` ideas/beliefs/systems · `WORK` films,
books, matches, songs as works
